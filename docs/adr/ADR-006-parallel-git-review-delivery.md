# ADR-006 · 并行隔离、持续远程交付与标准审查包

状态：ACCEPTED，2026-10-23人类明确批准V2全部范围及Worktree并行。

最新决定覆盖先前无需Worktree、默认main单写开发偏好；历史消息和G0/G1-ENG原始证据保留，不改写历史事实。Master是main唯一集成责任人而非全部源码唯一作者。
