# 恢复实施经验增量

- Content-Length只作早拒绝提示；真正上限在读取流中按65537字节检测，先于反序列化、签发和业务调用。用真实chunked与HTTP2验证。
- PostgreSQL优化器不保证WHERE短路：sequence权限函数使用CASE保护；最短真实负例先于重跑大套件。
- 内部deadline与客户端取消必须分别保留真实阶段和终态；用源暂停超时及真实浏览器Abort双向验证。
- 父详情刷新与子目录操作需对称互锁、同步入口防同tick及实例owner释放；代际安全检查不能删除来掩盖丢任务URL。
- 工具/测试失误保留原始失败：stdin关闭、瞬态RUNNING观测、权限属性不可见、空日志载体、最低执行数包含skip、结构化解析器链接过早清理。补证不得改写原时间点结论。
- 精确资源删除须核验身份/引用/版本/过期、命令exit与after缺席；旧default bridge身份漂移是独立UNKNOWN事实，不扩大删除或伪称旧ID保留。
- 包的最终自检不可写成已发生在其自己的输入中；用唯一已提交Head及包外实际重开/扫描回执闭合。
