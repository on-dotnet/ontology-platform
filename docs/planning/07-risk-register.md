# 07 · 风险登记

风险与控制方案为 **PROPOSED**；执行验证均 **NOT_RUN**。仓库事实与环境观察见 [00](00-current-state-audit.md)。

| 风险／等级 | 信号与触发条件 | Owner／门禁及退路 |
|---|---|---|
| 零实现被误判为已有成果／高 | 报告无源码或运行证据却称通过 | Master；按新工程起步，NOT_RUN不得转PASS |
| 工具链漂移／高 | SDK/EF/锁图不一致、浮动版本 | Platform；固定SDK、工具、包及镜像，CI锁定恢复 |
| 发布混版／极高 | active引用缺图/包、运行中版本漂移 | Publishing；CAS、回验、故障注入阻断G2 |
| 本体有损／极高 | 公理或字面量在编辑导出后消失 | Semantic；同构及源码保留测试，必要时只读 |
| Jena HA或恢复不满足／高 | 目标拓扑无法达成恢复目标 | SRE；独立PoC，限制拓扑或审批RDF4J备选 |
| 身份误合并／极高 | 跨厂重号、历史编码造成错误谱系 | Connectors；显式冲突及AMBIGUOUS，不猜测合并 |
| 源权限越界／极高 | 任意SQL、生产写权限、越厂读取 | Security；只读账号、受控计划、Adapter及工具Guard |
| MAF恢复重复副作用／高 | 接管后重复命令或审批失效 | AI；租约/fencing/幂等，失败限制自动恢复 |
| SSE不可靠／高 | 代理缓冲、游标缺失、终态冲突 | Backend/FE；持久事件及双实例恢复测试 |
| RustFS兼容外推／高 | 发布包成功但观测存储失败 | SRE；逐消费者验证，独立替代方案需审批 |
| 第三方许可或维护问题／高 | 未登记依赖、无法离线交付 | Quality；依赖清单/SBOM/许可门禁 |
| 框架指令覆盖／中 | Next生成文件改变根治理规则 | Frontend；应用级AGENTS、管理区块差异审查 |
| Aspire实验API绑定／中 | 升级破坏Next编排或发布 | Platform；通用资源默认，实验helper独立PoC |
| 因果性夸大／极高 | 缺证据仍输出确定根因 | AI/业务专家；反证Eval、未知标识、人工调查退路 |
| 生产目标不明／高 | 无硬件、SLO、RPO/RTO或保留期 | 项目负责人/SRE；阻止G8生产承诺和验收 |
| Design System被目录优化隐式降级／高 | 将暂缓packages/ui写成已批准或删除共享设计能力 | Master/Frontend；ADR-001解释并明确审批，保持Tokens、组件及统一交互能力 |

所有风险在触发时写任务卡和证据；风险关闭必须有执行结果或明确接受记录。G0总体通过和本次归档均不关闭产品兼容、安全、性能或恢复风险。
