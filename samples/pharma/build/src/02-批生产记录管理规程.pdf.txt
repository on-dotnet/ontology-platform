本文件为示例资料，企业、产品、人员和编号均为虚构。

# 1 目的
规定批生产记录的设计、发放、填写、复核、审核和归档要求，保证每一个生产批次的生产过程、所用物料、设备和操作人员均有据可查，满足产品追溯和放行审核的需要。

# 2 范围
本规程适用于本公司所有药品的批生产记录，包括作为其组成部分的批包装记录。物料接收记录、检验原始记录和设备使用日志不属于批生产记录，但批生产记录中应能引用其编号。

# 3 职责
质量保证部负责批生产记录模板的审核与批准、空白记录的受控发放、批生产记录的审核与归档。
生产部负责依据工艺规程起草批生产记录模板；车间负责按批领用、填写、整理并移交批生产记录。
各工序操作人员负责如实、及时填写本工序记录；复核人负责对关键操作和计算进行独立复核。
质量受权人在产品放行前审阅批记录审核结论。

# 4 定义
批生产记录：一个批次的产品从投料到包装完成的全部生产记录，能反映该批产品的生产历史和与质量有关的情况。本公司内部通常简称"批记录"，英文缩写为BPR。
批包装记录：内包装和外包装工序的记录，是批生产记录的组成部分。
清场：每道工序结束后，将与本批生产有关的物料、中间产品、废弃物、文件和标签清离操作间，并对设备、容器和环境进行清洁的过程。
清场合格证：清场完成并经QA检查合格后签发的证明，表明该操作间可以进行下一批次的生产。
物料平衡：产品或物料的实际产量或实际用量及收集到的损耗之和与理论产量或理论用量之间的比较。

## 5.2 附入批记录的其他文件
下列文件的原件或复印件附入批记录：中间产品检验报告单、清场合格证正本及上一批清场合格证副本、偏差报告复印件、标签和说明书实样、物料退库单。

# 6 记录的发放
批记录由QA根据批生产指令按批号发放。空白记录每页印有表单编号、版本号和"第 页 共 页"，发放时QA在每页填写批号并加盖受控章，登记产品名称、批号、发放页数、领用人和日期。记录损坏需要补发时，须说明原因并经QA批准，损坏页随批记录归档，不得销毁或自行复印。

# 7 记录的填写
## 7.1 一般要求
记录应及时、准确、清晰、不易擦除，使用黑色或蓝黑色墨水笔填写，不得使用铅笔或修正液。需要更正时在原内容上划一横线，使原内容仍可辨认，在旁边填写正确内容并签名、注明日期和理由。不需填写的栏目划斜线或填写"N/A"。时间采用24小时制，数值保留的位数与工艺规程一致。
## 7.2 批号与工序记录的对应
每份工序记录的页眉填写产品名称、规格和批号，批号应与批生产指令单一致。同一生产批分两台压片机压片时，每台压片机各填写一份压片记录和压片中间控制记录，记录中注明压片机的设备编号，例如EQ-YP-001，两份记录的产量之和用于计算压片阶段的物料平衡。包衣分锅进行时，每锅填写一份包衣记录，锅号依次编为1、2、3。外包装跨日进行的，仍使用同一批号，在记录中分日登记数量。
称量配料记录中须逐项记录每种物料的物料批号、检验报告单编号和实际称量量，例如2611035批使用的甲氧芬物料批号为Y2611004，从而使每个成品批都能追溯到所用的每一个物料批。
## 7.3 设备与操作间信息
每道工序开工前须在记录中填写：操作间编号、所用设备编号、设备清洁状态和清洁有效期、计量器具校准有效期，并附上一批的清场合格证副本。设备清洁已超过有效期的不得开工，须重新清洁并填写设备清洁记录后再生产。
## 7.4 工艺参数与中间控制
关键工艺参数按工艺规程规定的频次记录。实测值超出控制范围时，在记录中将该数值圈出，注明"见偏差报告"及偏差编号，并立即报告。中间控制结果由中控员填写，异常结果须复测确认后再报告。
## 7.5 中间产品请验与交接
总混颗粒、素片和包衣片完成后，由班组长填写中间产品请验单交QC取样。中间产品在检验结果出来前挂"待验"标识，检验合格并经QA放行后方可转入下一工序，交接时填写中间产品交接单，交接双方核对品名、批号、桶数和净重。本规程中的"待压颗粒"即工艺规程中的总混颗粒，"片芯"即素片。
## 7.6 打印附件与电子数据
压片机的主压力趋势、包衣机的温度与喷液记录、铝塑包装机的温度记录等由设备打印或导出的数据，作为相应工序记录的附件。打印件须注明批号、设备编号和打印时间，由操作人员签名，粘贴在指定位置；热敏纸打印件须复印后与原件一同保存。设备内存储的电子数据由设备工程部定期备份，备份文件按设备编号和日期命名，不得删除或修改。
## 7.7 批记录的整理与移交
每道工序结束后，班组长检查本工序记录是否填写完整，将记录、打印附件、中间产品检验报告单和清场合格证按表单编号顺序整理，交车间资料员。资料员按批收齐全部工序的记录后核对页数，与发放登记的页数一致后，连同移交清单交车间主任审核。移交过程中不得拆散装订，发现缺页立即查找并报告QA。

# 8 清场记录与清场合格证
每道工序结束、更换批号或更换品种时必须清场。清场内容包括：本批物料、中间产品和废弃物清离操作间；设备、容器和工器具清洁；本批记录、标签和状态标识清离；地面、墙面和回风口清洁。清场记录由操作人员填写、班组长复核，QA检查合格后签发清场合格证。
清场合格证的编号由房间编号和批号组成，例如压片间一在2611035批生产结束后清场，所签发清场合格证的编号为D-206-2611035。清场合格证一式两联：正本附入本批批记录；副本留在操作间，作为下一批开工的依据，下一批开工时附入下一批的批记录。清场合格证的有效期为72小时，超过有效期须重新清场。

# 9 物料平衡计算
每个阶段结束后，由班组长按物料平衡计算表计算物料平衡和收率，复核人独立复核。计算方法和限度见工艺规程。下表为压片阶段的计算示例。
| 项目 | 数值 |
| 批号 | 2611033 |
| 阶段 | 压片 |
| 总混颗粒领用量 | 120.62kg |
| 素片产量 | 119.20kg |
| 取样量（中控与QC） | 0.38kg |
| 可收集的尾料 | 0.62kg |
| 不合格素片及筛片粉末 | 0.31kg |
| 物料平衡 | （119.20＋0.38＋0.62＋0.31）÷120.62×100%＝99.9% |
| 收率 | 119.20÷120.62×100%＝98.8% |
| 结论 | 在限度内（物料平衡98.0%～100.0%，收率≥96.0%） |
物料平衡超出限度时，班组长立即报告车间主任和QA，本阶段产品挂"待验"标识暂停流转，按偏差管理规程处理。

# 10 偏差在批记录中的引用
生产过程中发生的偏差，包括设备故障、参数超限、物料平衡超限、清场不合格等异常事件，须在发生工序的记录中注明偏差编号，偏差报告复印件附在批记录的"偏差与变更"部分。批记录审核时，QA核对批记录中引用的每一个偏差编号在偏差台账中的状态。
例如2611035批的压片记录中注明"平均片重超出控制范围，见DEV-2026-041"，该批的批生产记录审核单上须写明DEV-2026-041的处理结论和关闭日期。所引用的偏差尚未关闭的，批记录审核结论为"待定"。

# 11 批记录的审核
## 11.1 车间审核
一批的全部工序结束后3个工作日内，车间主任按批生产记录审核单逐项审核，确认记录完整、批号一致、参数在范围内、物料平衡符合规定、清场合格证齐全、偏差已在记录中注明，签字后交质量保证部。
## 11.2 QA审核
QA审核员收到批记录后5个工作日内完成审核，审核要点见下表。审核发现的问题以书面方式反馈车间，由原填写人按第7.1条更正，不得由他人代改。
| 审核项目 | 审核要点 |
| 完整性 | 所有表单齐全，页码连续，无缺页、无空白栏 |
| 批号一致性 | 每页批号与批生产指令单一致 |
| 物料 | 物料批号、检验报告单编号与仓库发料记录一致，物料状态为合格 |
| 设备与操作间 | 设备编号、清洁有效期、校准有效期齐全，清场合格证正副本齐全 |
| 工艺参数 | 关键工艺参数在控制范围内，超限处已注明偏差编号 |
| 中间产品 | 检验结果合格并有QA放行记录 |
| 物料平衡 | 各阶段物料平衡与收率在限度内，计算经复核 |
| 偏差 | 引用的偏差已完成调查并关闭，或已评估对本批无影响 |
| 签名 | 操作人、复核人签名齐全，签名与签名样张一致 |
QA审核结论分为"合格""不合格"和"待定"三种。审核结论和审核单随批记录提交质量受权人，作为产品放行的依据之一。

# 12 归档与保存
批记录审核完毕后由质量保证部统一归档，按产品和批号顺序存放于档案室，保存至产品有效期后一年。借阅批记录须经质量保证部经理批准，原件不得带离档案室。电子数据（如压片机主压力趋势数据）应与纸质批记录对应保存，保存期限相同。

# 13 培训
新入职人员和转岗人员须接受本规程培训。质量保证部每年组织一次记录填写规范的再培训，并抽查批记录的填写质量，结果纳入年度质量回顾。
