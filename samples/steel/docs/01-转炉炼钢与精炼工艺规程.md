# 转炉炼钢与炉外精炼工艺规程（合成示例）

> 本文为平台演示用的合成资料，参考公开的通用工艺知识编写，不代表任何企业的实际规程。

## 1 适用范围

本规程适用于 120 吨顶底复吹转炉冶炼普通碳素结构钢（如 Q235B）及其后续的 LF 钢包精炼。

## 2 术语

- **炉次**：转炉从装料到出钢完成的一次冶炼过程，以炉号唯一标识，炉号由年份、转炉编号和流水号组成，例如 2611-2-0457。
- **钢种**：按化学成分和性能要求划分的钢的牌号，例如 Q235B。每个炉次只冶炼一个钢种。
- **钢包**：盛装并运输钢水的耐火容器，也称盛钢桶。钢包有包号，循环使用。
- **出钢温度**：钢水从转炉倒入钢包时测得的温度，单位为摄氏度（℃）。
- **出钢量**：一个炉次倒入钢包的钢水重量，单位为吨（t）。

## 3 转炉冶炼

### 3.1 装料

每个炉次装入铁水和废钢，铁水比不低于 85%。装料前操作工须在生产系统中登记炉号、钢种和计划出钢量。

### 3.2 吹炼与终点控制

吹炼终点的碳含量按钢种要求控制。终点测温取样后，记录终点温度和终点碳含量。Q235B 的目标出钢温度为 1650～1670 ℃。

### 3.3 出钢

出钢时向钢包加入脱氧合金。每个炉次出钢后，记录出钢温度、出钢量和所用钢包的包号。钢水由钢包吊运至 LF 精炼炉。

## 4 LF 钢包精炼

### 4.1 工序要求

钢包到达 LF 精炼炉后进行加热、造渣和成分微调。精炼结束时测温并取成品样，成品样的化学成分须满足钢种的成分要求。

### 4.2 精炼记录

每个炉次在 LF 精炼炉的处理称为一次精炼处理，须记录进站温度、出站温度、精炼时间（分钟）和喂线量。精炼结束后，钢包由行车吊运至连铸机的钢包回转台。

## 5 化学成分控制

Q235B 的成品化学成分要求如下（质量分数，%）：

| 元素 | 要求 |
|---|---|
| 碳 C | ≤ 0.20 |
| 硅 Si | ≤ 0.35 |
| 锰 Mn | ≤ 1.40 |
| 磷 P | ≤ 0.045 |
| 硫 S | ≤ 0.045 |

化学成分不合格的炉次不得送连铸，须改判钢种或回炉处理。
