@title 编码与代码规则手册
@author 示例钢铁公司 制造管理部

@sheet 编码使用
| 使用环节 | 登记要求 |
| 领号 | 实物形成或单据建立时领号。年份取创建时刻的公历年后两位，以北京时间（+08:00）为准。样签可随取样任务先行领号，取到实物后核销，另记实际取样时刻。年度流水从1起，按位数左补零，已经作废的流水留存。 |
| 抄录 | 编码用大写字母、数字，保留前导零。订单行和库位在指定位置保留半角连字符。编号无校验位，验收还须核对实物标记和原始记录。 |
| 查炉 | 逐炉登记实际炉座、开始冶炼的年和流水。若编号段与炉座交接卡有出入，照录两项，另记差异供复核。 |
| 查坯 | 板坯号内只有一个编号炉次。查钢水来源须看本坯的逐炉来料记录，混浇时可以有两个来源。 |
| 查卷 | 查出口卷取实绩取得直接母卷。分卷逐一登记子卷与母卷的区段，合卷逐一登记焊入的母卷。重新卷取形成新实物时另发号。 |
| 变更去向 | 换订单、改判、封闭、让步或移库沿用原实物号，另存审批单或移动事件。二次切割形成的各块新坯领新号，逐件注明原坯号。 |
| 分段复核 | 机组、年份、流号、流内序号和库位行列层均有各自的登记栏。仅有编码时先核凭证，再认定这些事实。 |
| 查牌号 | 订单写标准牌号、产品标准编号和版次，内部钢种用钢种编码。核对同一内部钢种可供应的多个牌号时逐规格检查。 |
| 查代码 | 先选业务表，再查代码。代码值为 1–10 位，只用大写字母和数字，采用有含义的缩写、单词或通行符号。化学元素用元素符号的大写，酸溶铝记 ALS。代码在本表内唯一，发布后保留原值和原义，停用后不复用。处置表的 RELEASE 表示放行，移动事件表的 RELEASE 表示释放落位。 |
| 读例号 | 例号仅供辨认段位。流水位数包括左侧补零，设备类型的字母数随类型而变。不得把号内流水当作产量、成分值或检验结果。 |

| 浇次 | Q＋铸机1位＋年2位＋流水4位 | 8 | Q1260045 | Q为浇次，1为铸机序号，26为建立年份，0045为年内流水，另列铸机和逐炉浇注顺序。 |
| 板坯 | S＋编号炉次后8位＋流号1位＋流内序号2位 | 12 | S22600123203 | S为板坯，22600123取自H22600123，2为第2流，03为本编号炉次该流第3块，来源炉次另记。 |
| 热轧卷 | R＋机组序号1位＋年2位＋流水6位 | 10 | R126000456 | R为热轧卷，1为热连轧机组序号，26为出口成卷年份，000456为年内流水。 |
| 冷轧段钢卷 | C＋机组段码2位＋机组序号1位＋年2位＋流水6位 | 12 | CPL126000789 | C为冷轧段卷，PL为酸轧，1为该类机组序号，26为成卷年份，000789为年内流水，其它出口段码见机组类型表。 |
| 包装件 | P＋年2位＋流水7位 | 10 | P260001234 | P为包装件，26为包装件创建年份，0001234为年内流水，另记所含实物号。 |
| 样品 | T＋年2位＋流水7位 | 10 | T260004567 | T为样品，26为样品建号年份，0004567为年内流水，从哪个炉次或实物取出另列。 |
| 检验批 | L＋年2位＋流水6位 | 9 | L26000321 | L为检验批，26为组批年份，000321为年内流水，批内所含的卷按卷号列出。 |
| 质量处置单 | N＋年2位＋流水6位 | 9 | N26000088 | N为处置单，26为建单年份，000088为年内流水，另列对象、依据判定和批准范围。 |
| 质量证明书 | Z＋年2位＋流水6位 | 9 | Z26000210 | Z为质量证明书，26为建证年份，000210为年内流水，证内逐卷列出覆盖件号。 |
| 销售订单 | D＋年2位＋流水6位 | 9 | D26001234 | D为销售订单，26为建单年份，001234为年内流水，订单头下另开行。 |
| 订单行 | 销售订单号9位＋连字符＋行号3位 | 13 | D26001234-010 | 左段为所属订单，中间为半角连字符，010为本单行号，通常按10递增，留出插行位置。 |
| 生产订单 | W＋年2位＋流水6位 | 9 | W26004321 | W为生产订单，26为下单年份，004321为年内流水，关联所服务的订单行。 |
| 发运单 | F＋年2位＋流水6位 | 9 | F26000777 | F为发运单，26为建单年份，000777为年内流水，装运明细列所发卷号、包装件和随货证号。 |
| 设备 | 机组类型代码＋机组序号1位 | 3至6 | BOF2、CC1、PLTCM1 | BOF、CC、PLTCM分别表示转炉、板坯连铸机、酸洗冷连轧机组，末位为该类机组序号。 |
| 天车 | CR＋库区代码3位＋库内序号1位 | 6 | CRCY12 | CR为天车，CY1为所属库区，2为该库区的天车序号。 |
| 库位 | 库区代码3位＋连字符＋行2位＋列2位＋层1位 | 9 | CY1-03121 | CY1为冷卷库，03为第3行，12为第12列，1为第1层，保留行列内的前导零。 |
| 内部钢种 | G＋流水4位 | 5 | G1023 | G为内部钢种，1023为目录流水，不按年重排，成分范围及适用牌号在钢种规范中查。 |

@sheet 质量处置类型
| 代码 | 中文名 | 说明 |
| RELEASE | 放行 | 依判定及授权解除交付或转序限制，注明放行的具体件号。 |
| HOLD | 封闭待处理 | 暂停交付和受限流转，保留原规格与件号，待凭证齐全后决定去向。 |
| DEGRADE | 降级 | 将原件按较低一档质量规格管理，订单是否保留另行决定。 |
| REASSIGN | 改判 | 原物料规格或订单分配作废，另指定适用规格或订单，须记前后去向。 |
| CONCESSION | 让步接收 | 保留原规格及偏差，凭批准限于指定订单行、数量和有效期交付。 |
| REWORK | 返修 | 按批准作业返修，留存处理实绩和复检结果，再决定能否放行。 |
| SCRAP | 报废 | 终止该件原产品用途，注销可供量，留存报废单和处置去向。 |

@sheet 判定结果
| 代码 | 中文名 | 说明 |
| CONFORM | 合格 | 判定对象符合记录所列版次及订单要求，登记依据和判定时间。 |
| NONCONFORM | 不合格 | 已查明指定要求有偏差，另开处置，记录偏差及处理范围。 |
| PENDING | 待判 | 尚缺判定所需证据或审批，待补齐后再登记结论。 |

@sheet 化学分析类型
| 代码 | 中文名 | 说明 |
| HEAT | 熔炼分析 | 精炼结束后取钢水样，每个炉次只有一条代表整炉、用于判定的熔炼分析。各元素结果分行列在同一分析记录号下。 |
| PROCESS | 过程分析 | 转炉终点样和精炼处理中所取样品的成分结果只用于工艺控制，不用于判定。逐样登记取样时刻，按各自的分析记录号归集元素结果。 |
| PRODUCT | 成品分析 | 取自具体成品，评定时核对适用产品标准及成品化学成分允许偏差。 |

@sheet 样品类型
| 代码 | 中文名 | 说明 |
| ENDPOINT | 转炉终点样 | 标识在转炉终点取得的钢水样，逐样登记炉次与取样时刻。 |
| REFINING | 精炼工位样 | 在精炼工位取的钢水样，包括处理中和处理结束时取的样，记机组、钢包测点和实际取样阶段。样品代码只说在哪里取样；处理中的样品供过程分析，处理结束后取得的判定样注明用于本炉熔炼分析。 |
| TUNDISH | 中间包样 | 在中间包取样，按现场记录登记对应浇次、炉次及取样位置。 |
| PRODUCT | 成品样 | 取自成品实物，另列卷号、位置和申请的检验项目。 |
| MECHANICAL | 力学性能样 | 供制作力学试样的样料，另记母材和取样方向，同一样板的各项试验分别出结果。 |
| COATING | 镀层试样 | 单独取下、只做镀层质量的试样；从力学性能样板上另取的镀层试片仍记在原样号下，不另编样号。 |

@sheet 来源证据等级
| 代码 | 中文名 | 说明 |
| MEASURED | 实测份额 | 有可复核的测量凭证，逐来源列份额，并注明按质量还是按长度计算。 |
| ESTIMATED | 估算份额 | 依据已说明的区间或规则估算，登记基准与计算依据。 |
| UNKNOWN | 份额未知 | 知道该炉参与，但没有份额依据，留空份额及基准，不能均分或填零。 |

@sheet 份额基准
| 代码 | 中文名 | 说明 |
| LENGTH | 按长度 | 份额按该炉钢水在坯上所占的切割计长区段计算，登记区段起止读数。 |
| MASS | 按质量 | 份额按称量或核定的钢水质量计算，登记称量凭证。 |

@sheet 采集方式
| 代码 | 中文名 | 说明 |
| MANUAL | 手工 | 测量人手持仪表测得，读数由人报出。 |
| AUTOMATIC | 自动 | 仪表自动测得并上传；由人转抄的自动读数仍记自动。 |

| T32 | 3.2型检验文件 | 3.2 | 记录需要相应各方确认的检验证书，并保留签认凭据。 |

| RELEASE | 释放落位 | 已确认天车卸下实物，按实际到达的库位及落位时刻更新位置。 |

| DISPATCH | 出厂 | 货物已办结出厂，按实际出厂时刻与发运单销账。 |
